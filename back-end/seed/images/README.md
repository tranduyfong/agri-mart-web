https://github.com/microsoft/fluentui-emoji

Giấy phép: MIT (xem `LICENSE-fluentui-emoji.txt`). Được phép dùng, sửa và phân phối lại, chỉ cần giữ lại thông báo giấy phép.

Script `seed/seed-demo.js` sẽ copy các ảnh này vào thư mục `uploads/` khi tạo dữ liệu mẫu.
