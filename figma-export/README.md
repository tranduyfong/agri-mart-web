# Agri-Mart — bản sửa desktop

[File Figma hiện tại](https://www.figma.com/design/AVHxdgKfgepM7o7kBjah5d)

Đã chuẩn bị lại 10 màn hình khách hàng theo website ở viewport desktop 1440px. [Gói plugin bản 2](./agri-mart-desktop-fix-v2.zip) sẽ cập nhật nội dung trong các frame desktop cũ và giữ ID, bản điện thoại.

**Chưa áp dụng trực tiếp vào Figma** vì hạn mức MCP Starter đang chặn công cụ đọc/sửa. Xem [hướng dẫn áp dụng và phạm vi kiểm tra](./repair-desktop-plugin/README.md).

Ảnh đối chiếu website nguồn nằm trong [thư mục previews](./repair-desktop-plugin/previews). Dữ liệu kiểm tra viewport và layer nguồn nằm trong [desktop-checks.json](./repair-desktop-plugin/desktop-checks.json).
